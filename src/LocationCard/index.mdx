## Usage example

The example below shows the official A2UI sample place. Directions opens Google Maps directions to the point and Open map opens it on openstreetmap.org; `directionsUrl` and `mapUrl` replace either link. The map needs `maplibre-gl` (see [MapView](/components/map-view#setup)).

<Demo of={DemoExample} />

## A2UI look

Set `variant="a2ui"` to draw the A2UI card.

<Demo of={DemoA2ui} />

## Name and coordinates only

Only `name`, `lat` and `lon` are required; `showActions={false}` hides the links.
