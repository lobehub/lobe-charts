`HeatmapChart` takes rows of `{ x, y, value }` (rename the keys with `x`, `y` and `value`). For a GitHub-style calendar of daily activity, use `Heatmaps`.

## Usage example

The example below shows request volume by weekday and hour. Columns and rows keep the order they first appear in `data`; the ramp at the top right reads from the lowest to the highest value.

<Demo of={DemoExample} />

## A2UI look

Set `variant="a2ui"` to draw the heatmap in the A2UI card with a `title` and `subtitle`; the ramp moves into the card header. The ramp colour is the first colour of the theme colour range in both looks (`color` overrides it).

<Demo of={DemoA2ui} />

## Values in cells

Small grids print each value in its cell; `showValues` turns this on or off. `color` sets the hue of the ramp.
