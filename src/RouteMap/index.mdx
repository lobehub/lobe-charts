## Usage example

The example below draws the official A2UI sample route. `coordinates` are `[[lon, lat], ...]` in travel order; the line runs from the theme success colour at the start to the accent at the destination. The map needs `maplibre-gl` (see [MapView](/components/map-view#setup)).
