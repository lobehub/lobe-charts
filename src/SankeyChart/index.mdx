## Usage example

The example below shows a signup funnel. Each row of `data` is a link; nodes are the names the links mention, coloured in the order they first appear. Parallel links are merged, and a link that would close a cycle is dropped.

<Demo of={DemoExample} />

## Custom keys and currency

`source`, `target` and `value` pick the keys of a link. `format="currency"` formats node labels and the tooltip.
