## Usage example

The example below shows a signup funnel. Each row of `data` is a link; nodes are the names the links mention, coloured from the theme colour range in the order they first appear. Parallel links are merged, and a link that would close a cycle is dropped.

<Demo of={DemoExample} />

## A2UI look

Set `variant="a2ui"` to draw the diagram in the A2UI card with a `title` and `subtitle`.

<Demo of={DemoA2ui} />

## Custom keys and currency

`source`, `target` and `value` pick the keys of a link. `format="currency"` formats node labels and the tooltip.
