## Usage example

## A2UI look

Set `variant="a2ui"` to draw the gauge in the A2UI card with a `title`. Colours are the same in both looks: the first colour of the theme colour range, and the theme error colour from `warnAt`.

<Demo of={DemoA2ui} />

## Formats and warning colour

`format` sets how the value and the range read. From `warnAt` (90% of the range by default) the arc turns to the negative colour.
