## Usage example

The example below groups services by area with `group`; each group gets one colour from the theme colour range and the legend lists the groups. Items too small for their name stay unlabelled; hover them for the name, value and share.

<Demo of={DemoExample} />

## A2UI look

Set `variant="a2ui"` to draw the treemap in the A2UI card with a `title` and `subtitle`; the legend moves into the card header.

<Demo of={DemoA2ui} />

## Without groups

Without a `group` key every item gets its own colour. `index` and `category` pick the name and value keys.

<Demo of={DemoFlat} />
