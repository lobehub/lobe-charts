## Usage example

The example below groups services by area with `group`; each group gets one colour and the legend lists the groups. Items too small for their name stay unlabelled; hover them for the name, value and share.

<Demo of={DemoExample} />

## Without groups

Without a `group` key every item gets its own colour. `index` and `category` pick the name and value keys.
