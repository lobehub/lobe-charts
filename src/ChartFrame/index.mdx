## Usage example

`ChartFrame` is the card every chart draws in with `variant="a2ui"`. Put any content inside and colour it with the same sources the charts use: `useThemeColorRange()` for series and `cssVar` tokens from `@lobehub/ui` for text and status colours, so it follows light and dark mode. The legend shows at the top right when it has more than one item; its colours default to the theme colour range.

## Aside and footer

`aside` replaces the legend, for a summary value or a key. `footer` goes under the content.
