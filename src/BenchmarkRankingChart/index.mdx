## Usage

Pass model icons and brand colors from the consumer (e.g. `@lobehub/icons`). The chart package does not bundle icons or brand color logic.

```tsx
import { BenchmarkRankingChart } from '@lobehub/charts';
import { Gemini, OpenAI } from '@lobehub/icons';

export default () => (
  <BenchmarkRankingChart
    data={[
      {
        color: Gemini.colorPrimary,
        icon: <Gemini.Avatar size={22} />,
        name: 'Gemini 3.8',
        provider: 'Google',
        score: 82.6,
      },
      {
        color: OpenAI.colorPrimary,
        icon: <OpenAI.Avatar size={22} />,
        name: 'GPT-6 Pro',
        provider: 'OpenAI',
        score: 73.9,
      },
    ]}
    labelWidth={280}
  />
);
```

## Accuracy with error bars

Use `accuracyFormatter`, `error`, and `showErrorBars` for AccuracyBar-style percentage, ± uncertainty, and horizontal error whiskers. Pass `labelWidth` to cap the left label column; omit it to fit the longest name. The X axis is off by default — set `showXAxis` / `showYAxis` to show coordinate axes.

## Highlighted items

Set `highlighted: true` on a record to accent its name / provider / score with `highlightColor` (defaults to `theme.gold`). Bar fill colors are unchanged.
